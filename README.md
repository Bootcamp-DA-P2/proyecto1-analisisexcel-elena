# 📊 Dashboard de Análisis de Préstamos Kiva

## 📌 Descripción

Este proyecto presenta un dashboard interactivo en Excel para analizar datos de préstamos de Kiva.
El objetivo es extraer insights relevantes sobre patrones de financiación, características de los prestatarios y tendencias generales.

---

## 🎯 Objetivos

* Analizar el comportamiento de financiación de préstamos
* Identificar los países y actividades más financiados
* Medir indicadores clave (KPIs)
* Crear un dashboard interactivo y visual

---

## 📈 Funcionalidades del Dashboard

### 🔹 KPIs principales

* Tasa de financiación de préstamos
* Promedio de cantidad solicitada
* Promedio de prestamistas por préstamo
* Tasa de participación femenina

---

### 🔹 Análisis visual

* Países más financiados
* Actividades más financiadas
* Distribución de la financiación

---

### 🔹 Interactividad

* Segmentadores (slicers) para filtrar datos
* Gráficos dinámicos conectados a tablas dinámicas
* KPIs actualizados en tiempo real

---

## 🛠️ Herramientas utilizadas

* Microsoft Excel
* Tablas dinámicas
* Gráficos 
* Segmentadores

---

## 📂 Dataset

El conjunto de datos proviene de préstamos de Kiva e incluye:

* Cantidad de préstamos
* Información de prestatarios
* Estado de financiación
* Datos geográficos y de actividad

---

## 🚀 Principales insights

* Identificación de países y actividades con mayor financiación
* Tendencias en la tasa de éxito de financiación
* Comportamiento medio de los prestamistas
